# Triton Autonomous Navigation Simulator

A C++17 project exploring autonomous navigation for unmanned
surface vessels (USVs).

## Planned Features

- Vessel position, heading, and speed simulation
- Waypoint navigation
- Obstacle detection
- Collision avoidance algorithms
- Fuel consumption modeling
- Automated testing

## Technologies

- C++17
- CMake
- Git

## Status

Early development.
